Fast by design.

Speed is the feature, not a side effect. Pun is built so you never sit and wait for your tools, whether that is one file on save or a whole monorepo in CI.

  • Native, all the way down

    One Rust binary. There is no PHP process to boot before it can read your code.

  • Every core, every file

    Format, lint and analyse spread the work across every core your machine has.

  • Fast enough to forget

    Put it on save, in a pre-commit hook and in every CI run. It keeps up with all three.

Three configs walk in. One walks out.

One unified config to manage everything. pun migrate writes it from your pint.json, phpstan.neon and rector.php.
