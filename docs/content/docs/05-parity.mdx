Pun's formatter is compared with Pint 1.32.1 and PHP-CS-Fixer 3.95.25. The results below are recorded runs, not a guarantee for every configuration.

Lint and analyse cover part of Rector, PHPStan, and Larastan. A rule that has an upstream mapping is not always implemented. The [rule reference](/docs/rules) marks unimplemented rules as Planned.

## Byte-for-byte output

Each run formats one copy of a project with Pint and another with `pun migrate` and `pun check --fix`. Then it compares every file. These are the results of the 2026-11-09 run against Pint 1.32.1:

| Project | Files | Identical | Differing |
| --- | --- | --- | --- |
| dev-null | 1,991 | 1,991 | 0 |
| larastan | 725 | 725 | 0 |
| laravel/framework | 3,483 | 3,483 | 0 |
| laravel/laravel | 66 | 66 | 0 |
| laravel/pint | 573 | 573 | 0 |
| pest | 757 | 757 | 0 |
| pinkary | 799 | 799 | 0 |
| pinkary (unformatted copy) | 799 | 799 | 0 |

In the unformatted Pinkary copy, Pint changes 346 files. Runs with the `psr12` preset also have zero differing files.

Two more checks run beside the file comparison:

- `scripts/cli-parity.sh` compares exit codes, machine reports, and changed files. The one intended difference: Pun exits 2 when it cannot run, where Pint exits 1.
- `scripts/fuzz-parity.sh` mutates real files and compares both tools. The scoreboard includes fuzz runs on Pinkary and laravel/framework, with CRLF and mixed line endings.

## Reproduce a comparison

To repeat a run, clone the [Pun repository](https://github.com/shipfastlabs/pun) and run these commands from its root. They need Rust 1.100 or later and system PHP, which runs the pinned Pint.

```bash
scripts/oracle.sh
scripts/corpus.sh pinkary
cargo run -p punphp-harness -- format --corpus pinkary --diffs 5
```

The [scoreboard](https://github.com/shipfastlabs/pun/blob/main/context/reports/scoreboard.md) records the full results and commands.
