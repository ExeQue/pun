When a coding agent runs Pun, Pun prints compact plain text instead of its usual output. `pun check` prints a summary line, then one line per finding, with paths relative to the project:

```
pun check: fail, 1 error, 2 files with fixes (412 checked, 0.21s)
app/A.php format/arrays/syntax, format/tags/blank-line-after-opening
app/B.php lint/style/no-alias-function [fix:unsafe] Master functions shall be used instead of aliases.
app/D.php:2 syntax-error Parse error: syntax error, unexpected token ";" on line 2.
```

The output has no color, progress indicator, or boxes. A clean run prints only the summary. Lists stop after 20 items. `-v` shows every item and the available diffs. The exit codes are the same as in human output.

`pun config` and `pun list-files` print their summary on stderr, so stdout stays plain TOML or one path per line.

## Detection and overrides

Pun detects agents, such as Claude Code, Cursor, and Codex, from the environment variables they set. A missing terminal does not turn agent mode on. `CURSOR_AGENT` turns it on, but `CURSOR_TRACE_ID` alone does not.

Overrides apply in this order, highest priority first:

| Override | Effect |
| --- | --- |
| `--agent` or `--no-agent` | Turns agent output on or off for this run |
| `PUN_AGENT=1` or `PUN_AGENT=0` | The same, from the environment |
| `PAO_DISABLE=1` or `PAO_FORCE=1` | Turns agent mode off or on. If both are set, `PAO_DISABLE` wins |

## Explicit reports

An explicit `--format` overrides agent output. For `format`, `lint`, and `check`, `--format=json` prints PHP-CS-Fixer's JSON report, and `--format=agent` prints Pint's JSON agent report. Neither one is Pun's plain-text agent output.

## Laravel Boost

The `punphp/pun` Composer package ships a [Laravel Boost](https://github.com/laravel/boost) guideline and a `pun-development` skill. They tell the agent to run `pun check --fix --dirty` after it changes PHP files, and to use Pun's package commands instead of Composer's. `php artisan boost:install` offers them when `composer.lock` lists `punphp/pun` as a direct dependency.
