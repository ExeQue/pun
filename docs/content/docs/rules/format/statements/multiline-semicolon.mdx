## What it does

Forbid multi-line whitespace before the closing semicolon or move the semicolon to the new line for chained calls.

## Configuration

```toml title="pun.toml"
[format.rules]
"statements/multiline-semicolon" = true
```

To skip it in some files, add a [`@pun-ignore-file`](/docs/configuration/ignore-comments) comment.
