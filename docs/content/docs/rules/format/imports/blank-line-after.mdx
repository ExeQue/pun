In the [`format-laravel`](/docs/rules/presets/format-laravel) and [`format-psr12`](/docs/rules/presets/format-psr12) presets. Safe fix.

## What it does

Each namespace use MUST go on its own line and there MUST be one blank line after the use statements block.

## Configuration

```toml title="pun.toml"
[format.rules]
"imports/blank-line-after" = true
```

To skip it in some files, add a [`@pun-ignore-file`](/docs/configuration/ignore-comments) comment.
