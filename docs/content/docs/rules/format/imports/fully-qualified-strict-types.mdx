## What it does

Removes the leading part of fully qualified symbol references if a given symbol is imported or belongs to the current namespace.

## Configuration

```toml title="pun.toml"
[format.rules]
"imports/fully-qualified-strict-types" = true
```

To skip it in some files, add a [`@pun-ignore-file`](/docs/configuration/ignore-comments) comment.
