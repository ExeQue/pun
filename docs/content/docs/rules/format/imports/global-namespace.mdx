## What it does

Imports or fully qualifies global classes/functions/constants.

## Configuration

```toml title="pun.toml"
[format.rules]
"imports/global-namespace" = true
```

To skip it in some files, add a [`@pun-ignore-file`](/docs/configuration/ignore-comments) comment.
