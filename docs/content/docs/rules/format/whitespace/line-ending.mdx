## What it does

All PHP files must use same line ending.

## Configuration

```toml title="pun.toml"
[format.rules]
"whitespace/line-ending" = true
```

To skip it in some files, add a [`@pun-ignore-file`](/docs/configuration/ignore-comments) comment.
