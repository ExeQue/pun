## What it does

PHP code MUST use only UTF-8 without BOM (remove BOM).

## Configuration

```toml title="pun.toml"
[format.rules]
"whitespace/encoding" = true
```

To skip it in some files, add a [`@pun-ignore-file`](/docs/configuration/ignore-comments) comment.
