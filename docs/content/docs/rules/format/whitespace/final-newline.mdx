## What it does

A PHP file without end tag must always end with a single empty line feed.

## Configuration

```toml title="pun.toml"
[format.rules]
"whitespace/final-newline" = true
```

To skip it in some files, add a [`@pun-ignore-file`](/docs/configuration/ignore-comments) comment.
