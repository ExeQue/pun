Not in any preset. Safe fix. Runs when doctrine is installed.

## What it does

Doctrine annotations must be indented with four spaces.

## Configuration

```toml title="pun.toml"
[format.rules]
"doctrine/annotation-indentation" = true
```

To skip it in some files, add a [`@pun-ignore-file`](/docs/configuration/ignore-comments) comment.
