Not in any preset. Safe fix.

## What it does

DocBlocks must start with two asterisks, multiline comments must start with a single asterisk, after the opening slash. Both must end with a single asterisk before the closing slash.

## Configuration

```toml title="pun.toml"
[format.rules]
"comments/multiline-delimiters" = true
```

To skip it in some files, add a [`@pun-ignore-file`](/docs/configuration/ignore-comments) comment.
