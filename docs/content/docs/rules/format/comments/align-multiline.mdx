## What it does

Each line of multi-line DocComments must have an asterisk [PSR-5] and must be aligned with the first one.

## Configuration

```toml title="pun.toml"
[format.rules]
"comments/align-multiline" = true
```

To skip it in some files, add a [`@pun-ignore-file`](/docs/configuration/ignore-comments) comment.
