## What it does

When making a method or function call, there MUST NOT be a space between the method or function name and the opening parenthesis.

## Configuration

```toml title="pun.toml"
[format.rules]
"functions/no-space-after-name" = true
```

To skip it in some files, add a [`@pun-ignore-file`](/docs/configuration/ignore-comments) comment.
