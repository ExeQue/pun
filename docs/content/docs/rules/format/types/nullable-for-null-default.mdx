In the [`format-laravel`](/docs/rules/presets/format-laravel) preset. Safe fix.

## What it does

Adds or removes `?` before single type declarations or `|null` at the end of union types when parameters have a default `null` value.

## Configuration

```toml title="pun.toml"
[format.rules]
"types/nullable-for-null-default" = true
```

To skip it in some files, add a [`@pun-ignore-file`](/docs/configuration/ignore-comments) comment.
