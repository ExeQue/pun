The PHP open and close tags. Also in [lint](/docs/rules/lint/tags) (1).

<CardGroup cols={2}>
<Card title="blank-line-after-opening" href="/docs/rules/format/tags/blank-line-after-opening">

Ensure there is no code on the same line as the PHP open tag and it is followed by a blank line.

In the `format-laravel` and `format-psr12` presets. Safe fix.

</Card>
<Card title="echo-syntax" href="/docs/rules/format/tags/echo-syntax">

Replaces short-echo `<?=` with long format `<?php echo`/`<?php print` syntax, or vice-versa.

Not in any preset. Safe fix.

</Card>
<Card title="full-opening" href="/docs/rules/format/tags/full-opening">

PHP code must use the long `<?php` tags or short-echo `<?=` tags and not other tag variations.

In the `format-laravel` and `format-psr12` presets. Safe fix.

</Card>
<Card title="linebreak-after-opening" href="/docs/rules/format/tags/linebreak-after-opening">

Ensure there is no code on the same line as the PHP open tag.

In the `format-laravel` preset. Safe fix.

</Card>
<Card title="no-closing" href="/docs/rules/format/tags/no-closing">

The closing `?>` tag MUST be omitted from files containing only PHP.

In the `format-laravel` and `format-psr12` presets. Safe fix.
