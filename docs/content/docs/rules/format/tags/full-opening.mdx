## What it does

PHP code must use the long `<?php` tags or short-echo `<?=` tags and not other tag variations.

## Configuration

```toml title="pun.toml"
[format.rules]
"tags/full-opening" = true
```

To skip it in some files, add a [`@pun-ignore-file`](/docs/configuration/ignore-comments) comment.
