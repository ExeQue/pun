This rule merges rules that used to be separate in Pun because each came from a different upstream tool:

- `lint/style/prefer-class-keyword`
- `lint/style/prefer-class-name-constant`

`pun migrate` maps every upstream name above to this rule, so a project that enabled several of them gets one rule. A pun.toml that still names an old ID stops with an error that names this rule, and `pun explain <old ID>` shows this page. See [merged rules](/docs/migrate/merged-rules).
