<RuleId id="lint/phpunit/prefer-specific-assertions" />

On when the [`phpunit` extension](/docs/configuration/pun-toml#extensions) is on. Unsafe fix: it can change behaviour.

## What it does

PHPUnit assertion method calls like `->assertSame(true, $foo)` should be written with dedicated method like `->assertTrue($foo)`.

## Configuration

```toml title="pun.toml"
[lint.rules]
"phpunit/prefer-specific-assertions" = "error"
```

To skip it in some files, add an [override](/docs/configuration/pun-toml#lint) or a [`@pun-ignore-file`](/docs/configuration/ignore-comments) comment.

## Options

| Name | Type | Allowed values | Default | Upstream name |
| --- | --- | --- | --- | --- |
| `assertions` | `list` | `assertEquals`, `assertNotEquals`, `assertNotSame`, `assertSame` | `["assertEquals", "assertNotEquals", "assertNotSame", "assertSame"]` | `assertions` |
