Off until you name it or its group. Safe fix.

## What it does

All PHPUnit test cases should have `@small`, `@medium` or `@large` annotation to enable run time limits.

## Configuration

```toml title="pun.toml"
[lint.rules]
"phpunit/require-size" = "error"
```

To skip it in some files, add an [override](/docs/configuration/pun-toml#lint) or a [`@pun-ignore-file`](/docs/configuration/ignore-comments) comment.

## Options

| Name | Type | Allowed values | Default | Upstream name |
| --- | --- | --- | --- | --- |
| `group` | `enum` | `small`, `medium`, `large` | `"small"` | `group` |
