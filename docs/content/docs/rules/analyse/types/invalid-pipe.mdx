## What it does

Reports a pipe callable whose first parameter is passed by reference. A pipe supplies a value, not a reference. The basic preset checks invokable $this receivers; essential and stricter presets check other callable expressions too.

## Configuration

```toml title="pun.toml"

"types/invalid-pipe" = "on"
```
