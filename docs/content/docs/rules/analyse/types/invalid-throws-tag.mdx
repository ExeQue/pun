## What it does

Reports `@throws` types that are not subtypes of `Throwable`. Standalone `void` means no exception is thrown. Both branches of a conditional type must be valid. A union containing `void` is invalid.

## Configuration

```toml title="pun.toml"
[analyse.rules]
"types/invalid-throws-tag" = "on"
```
