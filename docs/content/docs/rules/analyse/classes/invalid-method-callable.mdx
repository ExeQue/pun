In the [`analyse-basic`](/docs/rules/presets/analyse-basic) preset and every stricter one. Report only.

## What it does

Checks the receiver, method existence and visibility when creating a first-class instance method callable. Callable creation does not pass arguments to the method. The check-function-name-case option also checks method spelling.

## Configuration

```toml title="pun.toml"
[analyse.rules]
"classes/invalid-method-callable" = "on"
```

To skip it in some files or lines, add an [ignore comment](/docs/configuration/ignore-comments).
