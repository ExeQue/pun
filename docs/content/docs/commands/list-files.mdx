---
title: pun list-files
description: Show the files Pun will check.
---

Show the files a command will check with the current `pun.toml`.

## Usage

```bash
pun list-files [paths] [options]
```

```bash
pun list-files
pun list-files --command analyse
pun list-files -0 app | xargs -0 wc -l
```

## Options

| Option | Description |
| --- | --- |
| `--command <name>` | `format`, `lint` or `analyse`. |
| `-0`, `--zero-terminate` | End each path with a NUL byte, for `xargs -0`. |
| `--format json` | Print JSON. |
| `--config <path>` | Use this `pun.toml`. |

## What happens

- Starts from `[files] paths`, or the project root. Path arguments replace them.
- For analyse, uses `[analyse] paths` first.
- Removes `[files] exclude` and the command's own excludes.
- Lint and analyse also skip Blade, `bootstrap/cache`, `build`, `node_modules` and `storage`.
- Never lists `vendor/`.
- Prints one path per line, sorted, relative to the project root.

## Exit codes

| Code | Meaning |
| --- | --- |
| 0 | Printed. |
| 2 | The config could not be read. |
