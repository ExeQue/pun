---
title: pun extension
description: List the built-in extensions and whether each is on for the project.
---

An extension adds the rules and analysis for a framework or test tool. `pun extension list` prints each one's ID, `on` or `off`, and why.

```bash
pun extension list
pun extension list --format json
```

```text
laravel  on   Laravel's rules and Larastan's analysis: on in pun.toml
pest     off  Rules for Pest tests: pestphp/pest v4.1.0 is locked; turn it on with pest = "on" in [extensions]
phpunit  off  Rules for PHPUnit tests: not in pun.toml
```

| Extension | Adds |
| --- | --- |
| `laravel` | The `laravel` lint and analyse groups and Larastan's analysis. The `laravel-*` upgrade groups and `format/laravel/blade` stay opt-in |
| `pest` | The `pest` lint group |
| `phpunit` | The `phpunit` lint group |

An extension is on only when [`[extensions]`](/docs/configuration/pun-toml#extensions) sets it to `"on"`. A locked package never turns one on by itself. [`pun migrate`](/docs/commands/migrate) and [`pun init`](/docs/commands/init) write `"on"` for each extension whose package `composer.lock` locks.

## Options

| Flag | Meaning |
| --- | --- |
| `--format json` | Print a JSON array of each extension's `id`, `name`, `description`, `on`, `switch` (`on`, `off`, or `null` when pun.toml leaves it out), `packages`, and `groups`. |
| `--config <path>` | Read another `pun.toml`. Default: `pun.toml`, if it exists. |
