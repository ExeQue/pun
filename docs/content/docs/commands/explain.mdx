---
title: pun explain
description: Look up a rule by Pun ID or upstream name.
---

```bash
pun explain lint/style/no-alias-function
pun explain style/no-alias-function
pun explain no_alias_functions
```

The command prefix is optional when the name matches one rule. `pun explain` accepts upstream names, but `pun.toml` doesn't. For an upstream or old name, Pun prints the current Pun ID first. An unknown or unsupported name exits 2 with a reason.

## Output fields

| Field | Meaning |
| --- | --- |
| Rule ID and summary | Pun name and description |
| `group` | Group name and scope |
| `presets`, `sets`, or `preset` | Selections that enable the rule |
| `intent` | `correctness` or `suspicious`, when recorded |
| `fix` | `safe`, `unsafe`, `mixed` (safe only where types prove it), or `none` (report-only) |
| `fixed by` | Lint rule that can fix an analyse finding |
| `upstream` | Equivalent upstream names and tools |
| `docs` | The rule's page on this site |

The [rule reference](/docs/rules) also lists each rule's options.
