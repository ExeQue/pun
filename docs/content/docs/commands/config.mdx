---
title: pun config
description: Show the resolved config.
---

Show the final config after presets, sets, extensions and your settings.

## Usage

```bash
pun config [options]
```

```bash
pun config
pun config --format json
pun config --preset psr12
```

## Options

| Option | Description |
| --- | --- |
| `--format <fmt>` | `toml` (default) or `json`. |
| `--config <path>` | Use this `pun.toml`. |
| `--preset <name>` | Show a format preset without `pun.toml`. |

## What happens

- Prints the same sections as `pun.toml`: `[php]`, `[files]`, `[extensions]`, `[format]`, `[lint]` and `[analyse]`.
- Lists only the rules that are on, with levels and options.
- Shows each extension as `"on"` or `"off"`.
- Shows the PHP version: your setting, else the lowest `require.php` allows, else 8.3.
- Starts with a comment naming the config files it read.
- Changes nothing.

## Limitations

- A setting shown here isn't always supported at run time. See [`pun analyse`](/docs/commands/analyse#limitations).

## Exit codes

| Code | Meaning |
| --- | --- |
| 0 | Printed. |
| 2 | The config could not be read. |
