---
title: pun remove
description: Remove packages from composer.json, then update and install.
---

```bash
pun remove laravel/sanctum
pun rm 'spatie/*'
```

`pun remove` deletes packages from `require` or `require-dev`, then runs [`pun update`](/docs/commands/update). Packages that nothing else needs leave the lock and `vendor/`. `pun rm` is an alias.

Pun edits `composer.json` only after the requirements resolve. If the install fails, Pun restores `composer.json` and `composer.lock`.

## Options

| Option | Effect |
| --- | --- |
| `--no-update` | Edit `composer.json` only, without resolving or installing |
| `-p`, `--package=MEMBER` | Edit this [workspace](/docs/guides/workspaces) member's `composer.json` |

`pun remove` also takes the [`pun update`](/docs/commands/update#options) options except `--dry-run`, and every [`pun install`](/docs/commands/install#options) option.

## Exit codes

| Code | When |
| --- | --- |
| 0 | Removed and installed |
| 2 | No `composer.json`, unresolvable requirements, a failed repository, a failed install, or a removed package that is still installed because another package requires it (`composer.json` keeps the edit, as with Composer) |
